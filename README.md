## 🏗️ About the Project

**JR Engineering Enterprises** is a modern and responsive **web application** built using **HTML**, **CSS**, and **JavaScript**.  
It showcases a professional engineering and manpower service provider — presenting the company’s offerings, expertise, and contact details in a clean, user-friendly interface.

> 💡 *"Your Trusted Partner for Industrial & Engineering Solutions"*

---

## ✨ Features

| 🧩 Feature | 📋 Description |
|-------------|----------------|
| **🏠 Home Page** | Clean and engaging landing section with navigation to all pages. |
| **🏢 About Us** | Company overview, mission, and values presented clearly. |
| **🛠️ Services** | Lists manpower supply, contractor services, engineering, electrical, instrumentation, process & maintenance, and erection works. |
| **📩 Enquiry Form** | Interactive enquiry/contact form for client engagement. |
| **📞 Contact Page** | Displays company contact information including phone and email. |
| **📱 Responsive Design** | Fully compatible with all devices (mobile, tablet, desktop). |
