## 📖 About

**JR Engineering Enterprises** is a responsive single-page business website for a manpower supplier and engineering service provider based in Lingalavalasa, Andhra Pradesh. It presents the company, its services and contact details, and sends enquiries to a Google Form. The whole page can be switched between **English, Hindi, Tamil and Telugu** from the navbar.

<img src="https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png" width="100%">

## ✨ Features

| Feature | Description |
|---|---|
| 🏠 **Home** | Hero section with a fade-in/slide-up text animation and an "Explore Services" call to action |
| 🏢 **About Us** | "Who We Are", "Our Services" and "Why Choose Us?" cards |
| 🛠️ **Services** | Manpower Supply, Contractor, Engineering, Electrical, Instrumentation, Industrial Process & Maintenance and Erection Works, each with a "Know More" button |
| 📩 **Enquiry** | Separate calls to action for job seekers and agencies, linking to a Google Form |
| 📞 **Contact** | Email and phone links, address and an embedded Google Map |
| 🌐 **Multi-language** | Language selector (English / Hindi / Tamil / Telugu) that rewrites page text via `translations.js` |
| 📱 **Responsive** | Hamburger menu on small screens (closes automatically after a link is tapped) and CSS media queries |

## 🚀 Getting Started

**Prerequisites:** a modern web browser (Python 3 is optional, for a local server).

1. Clone the repository
   ```bash
   git clone https://github.com/Annepuuday111/JR-Engineering-Enterprises.git
   cd "JR-Engineering-Enterprises/JR Engineering Enterprise"
   ```
2. Open `index.html` directly in your browser, **or** serve the folder locally:
   ```bash
   python -m http.server 8000
   ```
3. Visit `http://localhost:8000`

No build step or dependencies are needed. Fonts and icons load from CDNs, so an internet connection is required for full styling.
